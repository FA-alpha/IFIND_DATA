# FA Agent 量化数据平台

> 基于同花顺 iFind 数据接口的多因子量化 Agent 自动化投研系统

## 📋 项目概述

本项目旨在构建一套**自动化 Agent 协作的多因子量化投研体系**，从数据采集、因子挖掘、模型训练、组合优化、策略回测到实盘交易形成完整闭环，并支持复盘回灌的自我迭代进化。

### 核心特性

- 🤖 **8个专业Agent协作** - 因子挖掘、模型研究、优化器、策略编写、回测、交易、复盘、风控
- 🔄 **闭环自迭代** - 复盘产出回灌到因子/模型研究，形成自进化体系
- 🛡️ **双层风控** - Guardrail硬规则 + 风控Agent智能评估
- 👨‍💼 **人工闸门** - L0-L3分级干预，关键节点人工卡位
- 📊 **血缘追溯** - 每笔亏损可追溯到源因子

## 🏗️ 系统架构

```
┌────────────────────────────────────────────────────────────────┐
│  L5  人机协同层  (审批工作台 · 干预入口 · 一键接管)             │
├────────────────────────────────────────────────────────────────┤
│  L4  编排调度层  (LangGraph · 状态机 · 审批闸门 · 血缘追踪)     │
├────────────────────────────────────────────────────────────────┤
│  L3  Agent层                                                   │
│  因子挖掘 → 模型研究 → 优化器 → 策略编写 → 回测 → 交易         │
│              ↑                                    ↓            │
│              └──── 复盘Agent ←── 风控Agent(全程) ←┘            │
├────────────────────────────────────────────────────────────────┤
│  L2  工具层  (因子DSL引擎 · cvxpy · 回测引擎 · 交易网关)        │
├────────────────────────────────────────────────────────────────┤
│  L1  数据层  (iFind API · PostgreSQL · Parquet · Redis)        │
└────────────────────────────────────────────────────────────────┘
```

## 🤖 Agent 列表

| # | Agent | 输入 | 核心职责 | 产出 |
|---|-------|------|---------|------|
| 1 | 因子挖掘 | 数据+回灌 | DSL生成/搜索，IC初筛 | 候选因子池 |
| 2 | 模型研究 | 候选因子 | 选模型/调参/训练 | 模型+评估卡 |
| 3 | 优化器 | 模型信号 | 组合优化，守约束 | 目标权重 |
| 4 | 策略编写 | 模型+权重 | 翻译成可执行策略 | 策略包 |
| 5 | 回测 | 策略包 | 多周期回测，过拟合检测 | 回测报告 |
| 6 | 交易 | 通过的策略 | 执行监控，拆单 | 执行状态 |
| 7 | 复盘 | 实盘结果 | 归因分析，衰减检测 | 回灌指令 |
| 8 | 风控 | 全程监控 | 事前评估+事中监控+事后复盘 | 风险评估/告警 |

## 🛡️ 风控体系

### 双层防线

```
产出物 → [Guardrail硬规则] → [风控Agent智能评估] → 下游Agent
              ↓                      ↓
           REJECT                NEED_REVIEW → 人工闸门
```

### 人工闸门分级

| 级别 | 场景 | 处置 |
|------|------|------|
| L0 | 常规操作 | 全自动，仅留痕 |
| L1 | 策略上线 | 单人审批 |
| L2 | 加杠杆/改红线 | 双人复核 |
| L3 | 紧急情况 | kill_switch |

## 🚀 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/FA-alpha/IFIND_DATA.git
cd IFIND_DATA

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 iFind 账号
cp config/config.example.yaml config/config.yaml
# 编辑 config.yaml 填入账号密码

# 4. 初始化数据库
python scripts/init_db.py

# 5. 启动数据采集
python -m src.scheduler.daily_update
```
