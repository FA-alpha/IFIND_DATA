#### 3.2.3 数据质量检查

**检查规则**：

| 规则 | 条件 | 处理 |
|------|------|------|
| 价格异常 | close <= 0 | 标记异常 |
| 涨跌幅异常 | abs(ret) > 0.2 且非新股 | 人工核实 |
| 成交异常 | vol = 0 且非停牌 | 标记异常 |
| 因子缺失 | 缺失率 > 10% | 告警 |
| 复权因子 | factor 突变 > 50% | 记录日志 |

**检查脚本**：
```python
def check_data_quality(date):
    """日度数据质量检查"""
    alerts = []
    
    # 1. 检查价格异常
    sql = """
    SELECT symbol FROM ml_cn_xxx_history_1d_xxx 
    WHERE time = %s AND close <= 0
    """
    
    # 2. 检查因子缺失率
    total = get_active_stock_count(date)
    filled = get_factor_count(date, 'pe_ttm')
    missing_rate = 1 - filled/total
    if missing_rate > 0.1:
        alerts.append(f"PE_TTM缺失率{missing_rate:.1%}")
    
    return alerts
```

**验收标准**：
- [ ] 每日检查脚本运行
- [ ] 异常数据标记
- [ ] 告警通知到位

```python
def filter_stocks(all_stocks, date):
    """过滤垃圾股"""
    filtered = []
    for code in all_stocks:
        # 获取基本信息
        info = THS_BD(code, 
            "ths_stock_short_name_stock;ths_ipo_date_stock;ths_listed_days_stock",
            date)
        
        # 过滤条件
        if 'ST' in info['name']:
            continue
        if info['listed_days'] < 60:
            continue
        
        # 获取流动性
        liquidity = THS_BD(code, "ths_avg_vol_20d_stock", date)
        if liquidity['avg_amount_20d'] < 10000000:  # 1000万
            continue
            
        filtered.append(code)
    
    return filtered
```

```python
def update_index_constituents(index_code, date):
    """更新指数成分股"""
    # 1. 获取最新成分股
    new_members = get_index_members(index_code, date)
    
    # 2. 获取当前成分股
    old_members = get_current_members(index_code)
    
    # 3. 识别变化
    added = set(new_members) - set(old_members)
    removed = set(old_members) - set(new_members)
    
    # 4. 更新注册表
    for symbol in added:
        add_index_member(symbol, index_code, date)
        # 为新增标的创建表
        create_daily_tables([symbol], current_year)
    
    for symbol in removed:
        remove_index_member(symbol, index_code, date)
    
    # 5. 记录变更日志
    log_constituent_change(index_code, date, added, removed)
```
