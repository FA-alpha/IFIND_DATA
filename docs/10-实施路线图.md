# iFind 数据平台实施路线图 v2.0

> 基于百亿私募量化标准，分批实现完整数据架构

---

## 一、总体目标

构建专业级 A股量化数据平台，支持多因子选股、策略回测、实盘信号生成。

**核心参数**：
- 历史起始：**2014年**（覆盖2015股灾完整周期）
- K线数据：**日线 + 分钟线**
- 标的范围：一期 **1994只**（沪深300+中证500+中证1000） → 二期 **万得全A**（~3500只）

### P0.3 分钟数据采集（Week 2-3）

**采集脚本**：
```python
from iFinDPy import THS_HF

def fetch_minute(symbol, start_date, end_date):
    code = f"{symbol}.{'SZ' if symbol.startswith(('0','3')) else 'SH'}"
    result = THS_HF(code, 
        'open;high;low;close;volume;amount',
        'Fill:Blank',
        start_date, end_date)
    return result
```

**分钟数据处理**：
| 时段 | 说明 |
|------|------|
| 9:15-9:25 | 集合竞价 → 合并到9:30 |
| 9:30-11:30 | 正常存储 |
| 13:00-14:57 | 正常存储 |
| 14:57-15:00 | 尾盘 → 合并到15:00 |

**数据量估算**：
```
1994只 × 240分钟 × 250天 × 12年 = ~144亿条
（实际去重约60亿条）
```

**并行策略**：
```python
# 多进程并行采集
from concurrent.futures import ProcessPoolExecutor

with ProcessPoolExecutor(max_workers=4) as executor:
    futures = [executor.submit(fetch_minute, s, '2014-01-01', '2026-12-31') 
               for s in symbols]
```

**验收**：

    limit_down TINYINT(1) DEFAULT 0,

);

**数据来源**：
```python
# 判断涨跌停
def check_limit(close, pre_close, is_st):
    limit = 0.05 if is_st else 0.10
    ret = (close - pre_close) / pre_close
    return 'UP' if ret >= limit - 0.001 else ('DOWN' if ret <= -limit + 0.001 else None)
```

#### 质量检查规则

| 规则 | 条件 | 处理 |
|------|------|------|
| 价格合理 | close > 0 | 异常标记 |
| OHLC一致 | H >= L, H >= max(O,C) | 异常标记 |
| 涨跌幅 | 非新股 abs(ret) > 20% | 人工核实 |
| 成交一致 | 停牌时 vol = 0 | 异常标记 |
