# iFind 量化数据平台 - 需求文档

> 版本: v1.0 | 更新日期: 2026-08-03

---

## 一、项目背景

### 1.1 业务背景

FourierAlpha 团队正在构建多因子量化选股系统，需要一套标准化的量化流程：

```
数据采集 → 因子计算 → 模型训练 → 策略优化 → 信号生成
```

当前痛点：**缺少基础数据**

为解决数据问题，决定对接同花顺 iFind 金融数据平台，获取 A 股市场的行情、财务、估值等全量数据。

### 1.2 数据源选择

**同花顺 iFind 数据接口** 优势：
- ✅ 覆盖 A 股、港股、美股全市场
- ✅ 支持 Python/MATLAB/R 等多语言
- ✅ 提供 PIT 时点数据，回测更准确
- ✅ 有免费版可用于开发测试

官方地址: https://quantapi.10jqka.com.cn/

## 二、功能需求

### 2.1 数据采集模块

#### 2.1.1 股票池管理
| 需求项 | 说明 | 优先级 |
|-------|------|-------|
| 全A股列表 | 每日更新全A股代码和基础信息 | P0 |
| 指数成分 | 沪深300/中证500/上证50等指数成分股 | P0 |
| 行业分类 | 申万/证监会行业分类 | P1 |
| ST/退市标记 | 风险股票标记 | P1 |

#### 2.1.2 行情数据
| 需求项 | 说明 | 优先级 |
|-------|------|-------|
| 日线行情 | OHLCV、涨跌幅、换手率 | P0 |
| 复权数据 | 前复权/后复权价格 | P0 |
| 分钟行情 | 1分钟/5分钟/15分钟线 | P2 |
| 实时行情 | 盘中最新价、买卖盘 | P2 |

#### 2.1.3 因子数据
| 需求项 | 说明 | 优先级 |
|-------|------|-------|
| 估值因子 | PE/PB/PS/市值/股息率 | P0 |
| 财务因子 | ROE/ROA/毛利率/净利率/EPS | P0 |
| 成长因子 | 营收增速/利润增速 | P0 |
| 资金因子 | 主力资金流向、融资融券 | P1 |
| 技术因子 | 波动率/Beta/动量 | P1 |

#### 2.1.4 辅助数据
| 需求项 | 说明 | 优先级 |
|-------|------|-------|
| 交易日历 | 沪深交易日、节假日 | P0 |
| 公告数据 | 财报发布日期(PIT关键) | P1 |
| 宏观数据 | GDP/CPI/PMI等 | P2 |

### 2.2 数据存储模块

#### 2.2.1 元数据存储 (PostgreSQL)
- 股票基础信息表
- 股票池配置与成分表
- 财务报表数据(PIT模式)
- 交易日历表
- 数据更新日志

#### 2.2.2 行情/因子存储 (Parquet)
- 日线行情 - 按月分区
- 分钟行情 - 按日分区
- 因子数据 - 按因子类型分目录

#### 2.2.3 缓存层 (Redis)
- 实时行情缓存
- 热点查询缓存

### 2.3 数据服务模块

#### 2.3.1 数据访问 API
```python
# 示例接口
class DataService:
    def get_stock_pool(pool_id, date) -> List[str]
    def get_daily_quotes(codes, start, end) -> DataFrame
    def get_factor(codes, factor_name, date) -> DataFrame
    def get_factor_series(codes, factor_name, start, end) -> DataFrame
```

#### 2.3.2 数据质量检查
- 数据完整性校验
- 异常值检测
- PIT 数据一致性验证

### 2.4 调度与监控

#### 2.4.1 日更新任务
| 任务 | 执行时间 | 说明 |
|-----|---------|------|
| 股票池更新 | 18:00 | 更新成分股变动 |
| 日线行情更新 | 18:00 | 拉取当日行情 |
| 因子数据更新 | 18:30 | 更新估值/财务因子 |

#### 2.4.2 监控告警
- 数据更新失败告警
- API 流量使用告警
- 数据质量异常告警

### 3.1 性能要求

| 指标 | 要求 |
|------|------|
| 单次查询响应 | < 1秒 (本地缓存) |
| 日更新耗时 | < 30分钟 |
| 历史回填速度 | > 50万条/小时 |

| 指标 | 要求 |
|------|------|
| 数据完整性 | 99.9% |
| 系统可用性 | 99% (交易日) |
| 数据备份 | 每日增量备份 |

- iFind 账号密码加密存储
- 数据访问日志记录

- 支持新增数据源 (万得/聚宽等)
- 支持新增因子扩展
- 支持分布式部署

## 四、API 流量预算

### 4.1 免费版月度预算

```
┌─────────────────────────────────────────────────────────┐
│                 免费版月度流量预算                        │
├──────────────────┬──────────────────────────────────────┤
│ 行情数据          │ 550万条/月                           │
│ 基本面数据        │ 180万条/月                           │
│ 特色数据          │ 5000条/月                            │
├──────────────────┴──────────────────────────────────────┤
│                    每日消耗估算                          │
├──────────────────┬──────────────────────────────────────┤
│ 全A股日线 (5000股) │ 5000 × 8字段 = 4万条/天             │
│ 估值因子 (5000股)  │ 5000 × 5字段 = 2.5万条/天           │
│ 财务因子 (5000股)  │ 5000 × 10字段 = 5万条/天            │
├──────────────────┼──────────────────────────────────────┤
│ 日均消耗          │ ~11.5万条                            │
│ 月度消耗          │ ~250万条 (22交易日)                  │
│ 是否够用          │ ✅ 基本够用，需优化                   │
└──────────────────┴──────────────────────────────────────┘
```

### 4.2 流量优化策略

1. **增量更新** - 只拉取新数据，不重复拉取历史
2. **批量请求** - 合并多股票请求，减少调用次数
3. **核心因子精简** - 只拉取高价值因子
4. **问财预筛** - 用智能选股先筛选，再拉取详细数据
