# 复权方案设计

## 一、什么是复权

股票发生除权除息（送股、配股、分红等）时，价格会出现跳空缺口。复权就是对历史价格进行调整，使价格序列连续可比。

```
除权前: 100元  →  送股10转10  →  除权后: 50元

如果不复权，回测计算收益时会认为跌了50%（实际没亏）
```

---

## 二、复权类型

### 2.1 前复权（Forward Adjusted）

**定义**：以最新价格为基准，向前调整历史价格

```
调整后价格 = 原始价格 × (最新复权因子 / 当日复权因子)
```

**特点**：
- ✅ 最新价格 = 实际交易价格
- ✅ 适合技术分析、画K线
- ❌ 历史价格会随时间变化（每次除权都要重算）

### 2.2 后复权（Backward Adjusted）

**定义**：以最早价格为基准，向后调整历史价格

```
调整后价格 = 原始价格 × 当日复权因子
```

**特点**：
- ✅ 历史价格固定不变
- ✅ 适合计算长期收益率
- ❌ 最新价格 ≠ 实际交易价格

### 2.3 不复权（Unadjusted）

**定义**：使用原始交易价格

**特点**：
- ✅ 真实历史交易价格
- ❌ 不能直接计算收益率
- ❌ 技术指标计算会失真

## 三、推荐方案

### 3.1 存储策略

**存储原始价格 + 复权因子，使用时按需计算**

```sql
-- 表结构
CREATE TABLE ml_cn_{symbol}_history_1d_{year} (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    open VARCHAR(50),           -- 原始开盘价（不复权）
    high VARCHAR(50),           -- 原始最高价（不复权）
    low VARCHAR(50),            -- 原始最低价（不复权）
    close VARCHAR(50),          -- 原始收盘价（不复权）
    factor DOUBLE DEFAULT 1,    -- 复权因子（累计）
    vol VARCHAR(50),            -- 成交量（股）
    vol_ccy VARCHAR(50),        -- 成交额（元）
    time INT DEFAULT 0,         -- Unix时间戳
    ...
);
```

### 3.2 复权因子来源

**iFind API 获取**：
```python
# 获取复权因子
THS_BD(codes, "ths_adj_factor_stock", date)
```

**复权因子含义**：
- `factor = 1` 表示无除权
- `factor > 1` 表示曾经送股/转增（累计）
- 例：`factor = 2` 表示累计送股1倍

### 3.3 使用时计算

```python
def get_adjusted_price(df, adjust_type='qfq'):
    """
    获取复权价格
    
    Args:
        df: 包含 open/high/low/close/factor 的 DataFrame
        adjust_type: 'qfq'=前复权, 'hfq'=后复权, None=不复权
    
    Returns:
        复权后的 DataFrame
    """
    if adjust_type is None:
        return df
    
    df = df.copy()
    
    if adjust_type == 'hfq':  # 后复权
        for col in ['open', 'high', 'low', 'close']:
            df[col] = df[col].astype(float) * df['factor']
    
    elif adjust_type == 'qfq':  # 前复权
        latest_factor = df['factor'].iloc[-1]
        for col in ['open', 'high', 'low', 'close']:
            df[col] = df[col].astype(float) * df['factor'] / latest_factor
    
    return df
```

## 四、不同场景的复权选择

| 场景 | 推荐复权方式 | 原因 |
|------|-------------|------|
| **因子计算** | 后复权/不复权 | 历史因子值需要稳定 |
| **收益率计算** | 后复权 | 正确计算实际投资收益 |
| **技术分析/画图** | 前复权 | 最新价格贴近实际 |
| **策略回测** | 后复权 | 收益计算准确 |
| **实盘交易** | 不复权 | 下单用真实价格 |
| **数据存储** | 不复权+因子 | 灵活，按需转换 |

## 五、复权因子更新机制

### 5.1 更新时机

| 事件 | 影响 | 更新操作 |
|------|------|---------|
| 送股/转增 | 因子增大 | 当日及之后更新 |
| 配股 | 因子变化 | 当日及之后更新 |
| 分红 | 因子变化（含税） | 当日及之后更新 |
| 合并/拆分 | 因子大幅变化 | 历史全部重算 |

### 5.2 更新流程

```python
def update_adj_factor(symbol, date):
    """
    更新复权因子
    """
    # 1. 从 iFind 获取最新复权因子
    new_factor = THS_BD(symbol, "ths_adj_factor_stock", date)
    
    # 2. 对比数据库中的因子
    old_factor = get_factor_from_db(symbol, date)
    
    # 3. 如果发生变化，更新当日及之后的记录
    if abs(new_factor - old_factor) > 0.0001:
        update_factor_in_db(symbol, date, new_factor)
        log_factor_change(symbol, date, old_factor, new_factor)
```

### 5.3 监控告警

```python
# 复权因子异常检测
def check_factor_anomaly(symbol, date, factor):
    """
    检测复权因子异常
    """
    alerts = []
    
    # 因子单日变化超过50%
    prev_factor = get_prev_factor(symbol, date)
    if prev_factor and abs(factor/prev_factor - 1) > 0.5:
        alerts.append(f"因子变化过大: {prev_factor} → {factor}")
    
    # 因子为负数或0
    if factor <= 0:
        alerts.append(f"因子异常: {factor}")
    
    return alerts
```

### 6.2 建议补充

1. **确认 factor 含义**：确保 iFind 返回的是累计复权因子
2. **添加日志表**：记录因子变更历史

```sql
CREATE TABLE ml_factor_change_log (
    id INT AUTO_INCREMENT PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL,
    trade_date DATE NOT NULL,
    old_factor DOUBLE,
    new_factor DOUBLE,
    change_reason VARCHAR(50),  -- 送股/配股/分红

    INDEX idx_symbol_date (symbol, trade_date)
```
