# iFind 量化数据平台 - 方案总览

> 最后更新: 2026-08-12

## 一、项目概述

### 1.1 目标
构建 A股量化数据平台，支持 FA Agent 多因子选股系统的数据需求。

### 1.2 范围
- 数据采集：iFind API 对接
- 数据存储：MySQL（按标的×年份分表）
- 数据服务：因子计算、回测支持

## 六、核心设计要点

### 6.1 表命名规范
```
ml_cn_{symbol}_history_{timeframe}_{year}
```
示例：`ml_cn_000001_history_1d_2024`

### 6.2 复权策略
- **存储**：原始价格 + 复权因子（factor字段）
- **回测**：使用后复权
- **展示**：使用前复权

### 6.3 成分股更新
- 每年 6月/12月 检测变化
- 新增标的自动建表
- 变更记录可追溯
