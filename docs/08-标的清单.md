## 一、数据存储架构

### 1.1 表命名规范

```
ml_{market}_{symbol}_history_{timeframe}_{year}
```

| 字段 | 说明 | 示例 |
|------|------|------|
| market | 市场标识 | `cn`=A股, `us`=美股, `btc`=加密货币 |
| symbol | 标的代码（纯数字） | `000001`, `600519`, `510300` |
| timeframe | 时间周期 | `1m`=分钟, `1d`=日线 |
| year | 年份 | `2024`, `2025` |

**A股示例**：
- `ml_cn_000001_history_1d_2024` - 平安银行 2024年日线
- `ml_cn_600519_history_1d_2024` - 贵州茅台 2024年日线
- `ml_cn_510300_history_1d_2024` - 沪深300ETF 2024年日线

### 1.2 表结构

```sql
CREATE TABLE ml_cn_{symbol}_history_1d_{year} (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    open VARCHAR(50),           -- 开盘价
    high VARCHAR(50),           -- 最高价
    low VARCHAR(50),            -- 最低价
    close VARCHAR(50),          -- 收盘价
    factor DOUBLE DEFAULT 1,    -- 复权因子
    vol VARCHAR(50),            -- 成交量
    vol_ccy VARCHAR(50),        -- 成交额
    vol_ccy_quote VARCHAR(50),  -- 预留
    confirm TINYINT(1) DEFAULT 1,
    time INT DEFAULT 0,         -- Unix时间戳
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_time (time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 1.3 标的注册表

```sql
CREATE TABLE ml_cn_stock_registry (
    id INT AUTO_INCREMENT PRIMARY KEY,
    symbol VARCHAR(10) NOT NULL,        -- 000001
    name VARCHAR(50),                   -- 平安银行
    market VARCHAR(10),                 -- SZ/SH
    stock_type VARCHAR(20),             -- STOCK/ETF/INDEX
    index_member JSON,                  -- ["hs300","zz500","zz1000"]
    status ENUM('ACTIVE','DELISTED','ST') DEFAULT 'ACTIVE',
    list_date DATE,
    delist_date DATE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_symbol (symbol)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 四、iFind API 获取方式

```python
from iFinDPy import THS_DR

def get_index_constituents(index_code, date):
    """获取指数成分股"""
    # index_code: 001005260=沪深300, 001005270=中证500, 001005274=中证1000
    result = THS_DR("p03291", 
        f"date={date};blockname={index_code};iv_type=allcontract",
        "p03291_f002:Y")
    return result

# 使用示例
hs300 = get_index_constituents("001005260", "20260813")  # 沪深300
zz500 = get_index_constituents("001005270", "20260813")  # 中证500
zz1000 = get_index_constituents("001005274", "20260813") # 中证1000
```

## 五、成分股调整机制

**调整时间**：每年 6月 / 12月

**调整流程**：
1. 获取最新成分股列表
2. 对比现有注册表
3. 新增标的 → 建表 + 历史数据回填
4. 剔除标的 → 更新 index_member 字段（保留历史数据）
