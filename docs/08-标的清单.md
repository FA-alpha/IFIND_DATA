### 阶段二：全市场股票池（~3000只）

**范围**: 中证全指（剔除垃圾股）

**过滤条件**:
- ✅ 上市满 60 天
- ✅ 非 ST/*ST
- ✅ 非停牌超过 20 天
- ✅ 非退市整理期
- ✅ 日均成交额 > 500万（近20日）
- ✅ 流通市值 > 10亿

**iFind 拉取代码**:

```python
from iFinDPy import *

def get_all_a_stocks(date_str):
    """
    获取全A股（剔除垃圾股）
    """
    # 1. 全A股代码
    all_a = THS_DR("p03291", 
        f"date={date_str};blockname=001005010;iv_type=allcontract",
        "p03291_f002:Y")
    
    # 2. 获取 ST 股票
    st_stocks = THS_DR("p03291",
        f"date={date_str};blockname=001005016;iv_type=allcontract",
        "p03291_f002:Y")
    
    # 3. 获取基本面数据（用于过滤）
    codes = all_a['p03291_f002'].tolist()
    
    basic_data = THS_BD(codes, 
        'ths_free_float_mv_stock;ths_avg_vol_20d_stock',
        date_str)
    
    # 4. 过滤
    filtered = []
    for code in codes:
        if code in st_stocks:
            continue
        # 流通市值 > 10亿
        if basic_data.get(code, {}).get('free_float_mv', 0) < 1e9:
            continue
        # 20日均成交额 > 500万
        if basic_data.get(code, {}).get('avg_vol_20d', 0) < 5e6:
            continue
        filtered.append(code)
    
    return filtered

# 使用
stocks = get_all_a_stocks('20260812')
print(f"全市场股票池: {len(stocks)} 只")
```

**预期结果**:
- 全A股: ~5300只
- 剔除ST: ~5100只
- 剔除流动性差: ~3500只
- 剔除小市值: ~3000只
