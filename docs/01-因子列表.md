## 一、行情因子（技术面）

| 因子名称 | 指标代码 | 说明 | 频率 |
|---------|----------|------|------|
| 收盘价 | `ths_close_price_stock` | 日收盘价 | 日 |
| 开盘价 | `ths_open_price_stock` | 日开盘价 | 日 |
| 最高价 | `ths_high_price_stock` | 日最高价 | 日 |
| 最低价 | `ths_low_price_stock` | 日最低价 | 日 |
| 前收盘价 | `ths_pre_close_price_stock` | 前一日收盘价 | 日 |
| 成交量 | `ths_vol_stock` | 成交量（股） | 日 |
| 成交额 | `ths_amt_stock` | 成交额（元） | 日 |
| 涨跌幅 | `ths_chg_ratio_stock` | 涨跌幅（%） | 日 |
| 换手率 | `ths_turnover_ratio_stock` | 换手率（%） | 日 |

### 1.2 复权价格
| 因子名称 | 参数 | 说明 |
|---------|------|------|
| 不复权价格 | `100` | 原始价格 |
| 前复权价格 | `101` | 向前复权 |
| 后复权价格 | `102` | 向后复权 |

### 1.3 衍生技术因子（需自行计算）
| 因子名称 | 计算方式 | 用途 |
|---------|---------|------|
| N日收益率 | `(close_t / close_{t-N}) - 1` | 动量因子 |
| N日波动率 | `std(returns, N)` | 风险因子 |
| N日均线 | `mean(close, N)` | 趋势因子 |
| 量价背离 | 价格与成交量的相关性 | 反转因子 |
| 振幅 | `(high - low) / pre_close` | 波动因子 |

## 五、风险因子

### 5.1 波动性
| 因子名称 | 计算方式 | 说明 |
|---------|---------|------|
| 20日波动率 | `std(returns, 20) * sqrt(252)` | 年化波动率 |
| Beta | `cov(stock, market) / var(market)` | 系统性风险 |
| 残差波动率 | 回归残差的标准差 | 特质风险 |

### 5.2 流动性
| 因子名称 | 计算方式 | 说明 |
|---------|---------|------|
| Amihud非流动性 | `abs(return) / volume` | 流动性因子 |
| 平均成交额 | `mean(amount, N)` | 流动性 |
| 平均换手率 | `mean(turnover, N)` | 活跃度 |

## 八、PIT 时点数据指标（重要！）

> 避免回测时使用未来数据

| 指标类型 | 指标代码 | 参数说明 |
|---------|----------|---------|
| 净利润(PIT) | `ths_np_atoopc_pit_stock` | `(日期, 报告期, 类型)` |
| 营收(PIT) | `ths_or_pit_stock` | `(日期, 报告期, 类型)` |
| ROE(PIT) | `ths_roe_pit_stock` | `(日期, 报告期, 类型)` |
| 财报披露日 | `ths_regular_report_actual_dd_stock` | 实际披露日期 |

### PIT 参数说明
```python
# 参数格式: '计算日期, 报告期, 类型'
# 类型: 1=累计值, 2=单季值

# 示例: 获取2024-05-15这一天可知的2024Q1净利润
THS_BD('000001.SZ', 'ths_np_atoopc_pit_stock', '2024-05-15,20240331,1')
```
