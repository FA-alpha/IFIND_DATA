# FA Agent 风控体系设计

> 版本: v1.0 | 更新日期: 2026-08-03

---

## 一、设计原则

1. **红线与 Agent 解耦**：风控不属于任何 Agent，是独立的护栏服务，所有 Agent 的产出都必须过它
2. **三处强制卡点**：事前(pre-trade)、事中(real-time)、事后(review)
3. **硬约束不可协商**：Agent 无权覆盖红线；越界产出直接被护栏打回，不进入下游
4. **双层防线**：Guardrail（硬规则）+ 风控 Agent（智能评估）

## 三、护栏服务架构

```
       所有Agent产出
            │
            ▼
   ┌─────────────────┐
   │  Guardrail 护栏  │  ← 读 risk_limits.yaml (唯一真相源)
   │  ① 契约schema校验 │
   │  ② 风控红线校验   │
   │  ③ 血缘完整性校验 │
   └─────────────────┘
            │
   ┌────────┼────────┐
   ▼        ▼        ▼
  PASS   REJECT   NEED_HUMAN
   │        │        │
   ▼        ▼        ▼
风控Agent  回灌   人工闸门队列
```

### Guardrail 护栏服务（硬规则）

```python
# src/guardrail/guardrail_service.py

class GuardrailService:
    """护栏服务 - 硬规则校验"""
    
    def __init__(self, risk_limits_path: str):
        self.risk_limits = self._load_risk_limits(risk_limits_path)
    
    def validate(self, artifact: dict) -> GuardrailResult:
        """
        校验产出物
        
        Returns:
            GuardrailResult: PASS / REJECT / NEED_HUMAN
        """
        checks = [
            self._check_schema(artifact),
            self._check_risk_limits(artifact),
            self._check_lineage(artifact),
        ]
        
        if any(c.status == 'REJECT' for c in checks):
            return GuardrailResult(
                status='REJECT',
                failed_checks=[c for c in checks if c.status == 'REJECT']
            )
        
        if any(c.status == 'NEED_HUMAN' for c in checks):
            return GuardrailResult(
                status='NEED_HUMAN',
                pending_checks=[c for c in checks if c.status == 'NEED_HUMAN']
            )
        
        return GuardrailResult(status='PASS')
    
    def _check_risk_limits(self, artifact: dict) -> CheckResult:
        """检查风控红线"""
        artifact_type = artifact['artifact_type']
        
        if artifact_type == 'factor':
            return self._check_factor_limits(artifact)
        elif artifact_type == 'model':
            return self._check_model_limits(artifact)
        elif artifact_type == 'allocation':
            return self._check_allocation_limits(artifact)
        # ... 其他类型
    
    def _check_factor_limits(self, artifact: dict) -> CheckResult:
        """因子红线检查"""
        evidence = artifact['evidence']
        limits = self.risk_limits['research_integrity']
        
        violations = []
        
        if evidence.get('ic_ir', 0) < limits['min_ic_ir']:
            violations.append(f"IC_IR {evidence['ic_ir']} < 阈值 {limits['min_ic_ir']}")
        
        if evidence.get('corr_to_existing', 0) > 0.7:
            violations.append(f"与现有因子相关性 {evidence['corr_to_existing']} > 0.7")
        
        if not artifact['payload'].get('economic_logic'):
            violations.append("缺少经济学逻辑解释")
        
        if violations:
            return CheckResult(status='REJECT', violations=violations)
        return CheckResult(status='PASS')
```

## 四、风控 Agent vs Guardrail 协作

```
                 产出物
                   │
                   ▼
            ┌─────────────┐
            │  Guardrail  │  ← 硬规则校验 (红线不可越)
            │   (护栏)    │     二元判断：PASS/REJECT
            └──────┬──────┘
                   │ PASS
                   ▼
            ┌─────────────┐
            │  风控 Agent │  ← 智能评估 (灰度判断)
            │   (评估)    │     风险评分 + 处置建议
            └──────┬──────┘
                   │
     ┌─────────────┼─────────────┐
     ▼             ▼             ▼
   PASS      NEED_REVIEW     REJECT
     │             │             │
  下游Agent    人工闸门        回灌
```

**分工**：
- **Guardrail**：硬约束，二元判断，不可协商，规则固定
- **风控 Agent**：软评估，风险评分，给建议，可学习进化

## 五、三处强制卡点

```
因子→模型→优化→策略──▶[Guardrail]──▶回测──▶[L1审批]──▶实盘──▶[实时Guardrail]──▶复盘
        └── 研究完整性红线 ──┘         事前          事中(回撤/撤单/偏离)
```

### 5.1 事前卡点（Pre-Trade）

| 检查项 | 红线 | 处置 |
|-------|------|------|
| 因子 IC_IR | < 0.3 | REJECT |
| 因子冗余度 | > 0.7 | REJECT |
| 模型 PBO | > 0.5 | REJECT |
| 样本外夏普 | < 阈值 | REJECT |
| 行业集中度 | > 15% | REJECT |
| 单票权重 | > 5% | REJECT |

### 5.2 事中卡点（Real-Time）

| 检查项 | 红线 | 处置 |
|-------|------|------|
| 净值水位 95% | 降杠杆至1.5x | 自动执行 |
| 净值水位 90% | 降杠杆至1.0x | 自动执行 |
| 净值水位 85% | HALT | L3接管 |
| 撤单次数 | > 450 | 转被动挂单 |
| 实盘偏离 | > 阈值 | L2人工 |
| 市场熔断 | 触发 | 暂停交易 |

### 5.3 事后卡点（Post-Trade）

| 检查项 | 处置 |
|-------|------|
| 因子衰减检测 | 回灌因子挖掘 |
| 市场结构变化 | 调整风控参数 |
| 规则有效性复盘 | 迭代红线配置 |

**水位线触发逻辑**：

```python
def check_water_level(nav: float, risk_limits: dict) -> WaterLevelAction:
    """检查水位线，返回处置动作"""
    
    water_levels = risk_limits['global']['water_levels']
    
    for level in water_levels:
        if nav <= level['nav']:
            return WaterLevelAction(
                level=level['nav'],
                target_leverage=level['leverage'],
                action=level.get('action', 'REDUCE_LEVERAGE'),
                alert_severity='CRITICAL' if level.get('action') == 'HALT' else 'WARNING'
            )
    
    return WaterLevelAction(level=1.0, action='NORMAL')
```

## 七、人工闸门详细设计

### 7.1 闸门分级

| 级别 | 触发场景 | 处置方式 | 超时处理 |
|------|---------|---------|---------|
| L0 全自动 | 因子初筛、常规回测 | 仅留痕，不阻断 | - |
| L1 单人审批 | 策略回测→实盘 | 审批工作台点批准 | 24h自动拒绝 |
| L2 双人复核 | 加杠杆/新市场/改红线 | 两人独立批准 | 48h自动拒绝 |
| L3 紧急接管 | 回撤触线/市场异常 | kill_switch | 即时冻结 |

## 九、风控指标计算

### 9.1 核心风险指标

| 指标 | 计算公式 | 用途 |
|------|---------|------|
| VaR (95%) | 历史模拟法 / 参数法 | 最大可能损失 |
| CVaR (ES) | E[Loss \| Loss > VaR] | 尾部风险 |
| 波动率 | std(returns) * sqrt(252) | 年化波动 |
| 最大回撤 | max(peak - trough) / peak | 历史最差 |
| Beta | cov(r, rm) / var(rm) | 市场风险暴露 |
| Sharpe | (r - rf) / vol | 风险调整收益 |

### 9.2 暴露分析

```python
def analyze_exposures(positions: dict, factors: pd.DataFrame) -> dict:
    """分析组合风险暴露"""
    
    exposures = {
        'industry': {},   # 行业暴露
        'factor': {},     # 因子暴露
        'concentration': {}  # 集中度
    }
    
    # 行业暴露
    for symbol, weight in positions.items():
        industry = get_industry(symbol)
        exposures['industry'][industry] = exposures['industry'].get(industry, 0) + weight
    
    # 因子暴露 (Barra风格因子)
    for factor_name in ['size', 'value', 'momentum', 'volatility']:
        factor_values = factors[factor_name]
        exposure = sum(positions[s] * factor_values[s] for s in positions)
        exposures['factor'][factor_name] = exposure
    
    # 集中度
    sorted_weights = sorted(positions.values(), reverse=True)
    exposures['concentration']['top5'] = sum(sorted_weights[:5])
    exposures['concentration']['top10'] = sum(sorted_weights[:10])
    exposures['concentration']['hhi'] = sum(w**2 for w in positions.values())
    
    return exposures
```
