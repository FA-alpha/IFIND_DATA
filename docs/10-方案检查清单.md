2. **交易日历**

   - 节假日标记

3. **行业分类**
   - 申万一级行业（31个）
   - 申万二级行业
   - 申万三级行业

### 3.2 中优先级（P1）

1. **数据更新日志表**
   ```sql
   CREATE TABLE ml_data_sync_log (
       id INT AUTO_INCREMENT PRIMARY KEY,
       data_type VARCHAR(50),      -- daily_quote/factor/etc
       symbol VARCHAR(20),
       sync_date DATE,
       status ENUM('SUCCESS','FAILED','PARTIAL'),
       records_count INT,
       error_msg TEXT,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   ```

2. **数据质量检查规则**
   - 价格为负数 → 异常
   - 涨跌幅超过±20%（非新股）→ 核实
   - 成交量为0但非停牌 → 异常
   - 因子值缺失率 > 10% → 告警

### 3.3 低优先级（P2）

1. 股指期货标的（IF/IH/IC）
2. 可转债标的列表
3. 分钟级数据存储方案
4. 实时行情推送架构
